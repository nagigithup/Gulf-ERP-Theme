# Security reporting

Report suspected vulnerabilities privately to the repository maintainers. Use
GitHub private vulnerability reporting if enabled, or obtain a private contact
channel before sending details. Do not put customer data, credentials, session
cookies or exploit payloads in public issues.

The supported target is Frappe/ERPNext v16. Consult docs/SECURITY_REVIEW.md for
review scope and known limitations. No third-party tracking or licence server
is required. Optional remote login images must be explicitly configured.
