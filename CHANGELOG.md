# Changelog

## 0.1.0 - 2026-11-12

- Independent Gulf ERP Theme package with complete recovered Lumen 0.9.1 features.
- Separated configuration resolution and nine maintainable frontend features.
- Isolated DocTypes, assets, defaults, managed roles and Arabic translation IDs.
- Mutating APIs accept POST only; favourites/history recheck record permissions.
- Navigation URLs reject active script schemes; notification observers disconnect.
- Workspace role collision checks and safer uninstall restoration preserve later edits.
- Added reduced-motion/focus refinements, setup guides, attribution and review reports.

Initial source release. No Marketplace publication or production deployment
has been performed. Validation limits are documented.
