# Screenshot and acceptance checklist

Use synthetic local records with no customer data. Capture the reference and Gulf
under identical user/language/theme/settings conditions at desktop, tablet and
phone sizes. Keep the original Lumen install as the comparison baseline.

- Apps home in English light and Arabic dark.
- Top bar, side menu, standard navigation and responsive drawer.
- Forms with summaries, guide, collapsed sections and mixed-direction codes.
- Lists with status chips, zero/multiple results and permission-filtered counts.
- Reports, tables, dashboard, dialogs, notifications, search and user menu.
- Appearance choices and administrator locks; language and dark-mode switching.
- Workspace builder create/edit/delete and visibility for permitted/denied users.
- All login layouts and optional image; offline local-font requests.
- Arabic corrections on/off, administrator-edited translations preserved.
- Theme disabled, role restore, upgrade and uninstall with backup/rollback.

Automated tests and browser automation remain subject to the user's approval.
